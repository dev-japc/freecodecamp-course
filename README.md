# FreeCodeCamp Python Exercises

A collection of short Python scripts created while following the FreeCodeCamp Python curriculum. Each script is self-contained and demonstrates a focused concept in algorithms, data structures, object-oriented programming, or simple utility functions.

## Table of Contents
- Overview
- Requirements
- Usage
- Project structure
- Example scripts
- Contributing
- License

## Overview
This repository is organized into thematic folders that group related Python examples:
- `algorithms/` — algorithm implementations and notes, such as binary search, merge sort, quick sort, selection sort, and Tower of Hanoi.
- `basic-functions/` — small function-based utilities and validators, including Caesar cipher, ISBN validation, medical record validation, and user configuration examples.
- `classes/` — class-based examples and practice scripts for building objects, budgets, and simple class hierarchies.
- `data-structures/` — implementations of fundamental data structures like linked lists and hash tables.
- `oop/` — object-oriented programming examples, covering inheritance, polymorphism, encapsulation, and application-style classes.

## Requirements
- Python 3.8 or newer
- No external dependencies required

## Usage
Run any script directly from the repository root:

```bash
python algorithms/implement-tower-hanoi-algorithm.py
python basic-functions/isbn-validator.py
python oop/build-a-media-catalogue.py
```

Each script is standalone, so you can open and run the files individually.
