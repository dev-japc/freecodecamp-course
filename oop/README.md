# Object-Oriented Programming Examples

This folder contains small object-oriented programming exercises and examples created while learning OOP concepts.

Each script is standalone and illustrates one or more of the following:
- class definition and instantiation
- encapsulation and property management
- inheritance and polymorphism
- method overriding and interfaces
- simple application-style class design

## Notable files
- `build-a-discount-calculator.py` — shows a class-based calculator for discounts.
- `build-a-game-character-stats.py` — example of a class for game character attributes.
- `build-a-media-catalogue.py` — a media catalogue implemented with classes.
- `build-a-polygon-area-calculator.py` — a class-based shape area example.
- `build-a-salary-tracker.py` — tracks salary-related calculations with classes.
- `email-simulator.py` — simple OOP email message simulation.
- `getters_and_setters_oop_.py` — demonstrates Python property getters and setters.
- `inheritance-notes.py` — notes and examples for inheritance.
- `polymorphism-notes.py` — notes and examples for polymorphism.

## Usage
Run any example from the repository root:

```bash
python oop/build-a-media-catalogue.py
```
